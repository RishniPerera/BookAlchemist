Book Alchemist 📚✨

Book Alchemist is a gamified social reading iOS application. It helps users discover and manage their reading, maintain consistent reading habits, set reading goals, and interact with other readers.


 🚀 Features

*   User Onboarding: Smooth animated introduction for new users.
*   Face ID Authentication:Secure biometric login.
*   Home Dashboard: Central hub for reading progress, streaks, XP, and challenges.
*   Personal Reading Library: Search real books via the Google Books API and save them to your Firebase library.
*   Reading Progress & Streak Tracking: Update reading progress and earn XP.
*   Reading Challenges & Gamification: Join challenges, earn XP, level up, and unlock achievements.
*   Community & Reader Interaction:Create posts, view feeds, and check the Global Leaderboard.
*   Push Notifications:Daily reading reminders.
*   Firebase Backend:Real-time Firestore database and Authentication.


💻 Advanced SDK Features

1.  App Intents and App Shortcuts Integration: Exposes reading functions (Current Reading, Progress, Challenges) to Siri and Spotlight.
2. Natural Language Smart Reading Text Analysis:Uses Apple's `NLTagger` on-device to identify and extract People, Places, and Organizations from highlighted text in the Reader.


🛠️ Technologies Used

*   Language:Swift
*   UI Framework: SwiftUI
*   Backend:Firebase (Auth, Firestore)
*   APIs:Google Books API
*   Apple Frameworks:LocalAuthentication, NaturalLanguage, AppIntents, UserNotifications
